# Notas+ ✦

Aplicação de notas open source e gratuita, sem conta, sem publicidade e sem servidor. PWA instalável em Windows e iPhone.

## Funcionalidades

- Criar e editar notas, etiquetas, cores e pesquisa
- Fixar, arquivar, enviar para o lixo e modo escuro
- Guardar localmente no navegador
- Exportar e importar ficheiros JSON
- Importação inteligente por ID: junta notas e conserva a versão com data de alteração mais recente
- Funcionamento offline após a primeira visita

## Publicar no GitHub Pages

No repositório, abrir Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Endereço previsto: https://xtvback.github.io/notas-plus/

## Instalar

Windows: abrir no Edge ou Chrome e escolher Instalar aplicação. iPhone: abrir no Safari, Partilhar → Adicionar ao ecrã principal.

## Privacidade e limitações

As notas ficam guardadas apenas no dispositivo, não no GitHub. Exporta cópias regularmente: a limpeza dos dados do navegador pode eliminar notas. A importação é manual, não sincronização automática. A resolução de conflitos depende da data do dispositivo. O ficheiro JSON não é encriptado; guarda-o em privado. As eliminações definitivas não se propagam, mas as notas no lixo são incluídas na exportação.
